# parser-airsoft — мониторинг новостей страйкбола

Собирает новости страйкбола из СМИ, ВКонтакте и Telegram, оставляет только
новые и по теме, раскладывает по разделам **Свердловская область / Россия / Мир**
и готовит черновик поста для группы ВК.

```
источники ──► фильтр по теме ──► регион и теги ──► без повторов ──► дайджест
 RSS, Google News   ключевые слова,    Урал / РФ / мир,    SQLite-база        digest_*.md  (для себя, с цитатами)
 ВК: стены, поиск   стоп-слова         игры, законы,       виденных ссылок    vk_post_*.txt (черновик поста)
 Telegram-каналы                       турниры, снаряга                       + сообщение в Telegram
```

Пост публикуется **вручную**: программа экономит время на поиске, а что выкладывать
и как переписать — решаете вы.

## Быстрый старт

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m airsoft_news
```

Результат — в папке `output/`. Без токенов работают Google News, любые RSS и Telegram-каналы.

Полезные ключи:

| Ключ | Что делает |
|---|---|
| `--days 3` | брать новости только за 3 дня |
| `--no-dedup` | показать всё, включая уже виденное |
| `--send-telegram` | прислать черновик поста себе в Telegram |
| `--config other.yaml` | другой файл настроек |

## Источники (`config.yaml`)

| Тип | Что читает | Ключ |
|---|---|---|
| `rss` | любой RSS/Atom, в т.ч. поиск Google News по запросу | не нужен |
| `telegram` | публичный канал через `t.me/s/<канал>` | не нужен |
| `vk_wall` | стена сообщества ВК (`wall.get`) | сервисный ключ приложения |
| `vk_search` | поиск по **всем** открытым постам ВК (`newsfeed.search`) | пользовательский токен |

У каждого источника можно указать:
- `region: ural | russia | world` — раздел по умолчанию. Если в тексте встретится город
  из `filters.ural_places` (Екатеринбург, Тагил, Первоуральск…), новость всё равно попадёт
  в «Свердловскую область»;
- `always_relevant: true` — для профильных групп и каналов, где каждый пост про страйкбол.

Что стоит добавить в первую очередь: группы страйкбольных команд и клубов Екатеринбурга
и области, региональные полигоны, федеральные страйкбольные паблики, Telegram-каналы
магазинов и организаторов крупных игр, зарубежные порталы с RSS.

Фильтры (`filters`) задаются основами слов: `страйкбол` найдёт и «страйкбольный», и «страйкболистов».
`exclude` отсекает барахолку, `tags` помечают тип новости (игра, законы, турнир, снаряжение).

## Токены

Токены передаются через переменные окружения, в `config.yaml` их писать не нужно.

- **`VK_TOKEN`** — создайте приложение на https://dev.vk.com (раздел «Мои приложения»).
  Для `vk_wall` хватит *сервисного ключа доступа* из настроек приложения.
  Для `vk_search` нужен токен пользователя (`newsfeed.search` с сервисным ключом не работает).
- **`TELEGRAM_BOT_TOKEN`**, **`TELEGRAM_CHAT_ID`** — создайте бота у @BotFather, напишите ему
  любое сообщение и узнайте свой chat id (например, через @userinfobot).

```bash
export VK_TOKEN=...
export TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=...
python -m airsoft_news --send-telegram
```

## Автозапуск каждый день

**GitHub Actions** (без своего сервера): workflow `.github/workflows/digest.yml` запускается
ежедневно в 09:00 по Екатеринбургу. Добавьте токены в *Settings → Secrets and variables →
Actions* (`VK_TOKEN`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`) — черновик придёт в Telegram,
а полные файлы лежат в артефактах запуска. Запустить вручную: вкладка *Actions → Run workflow*.

**Свой компьютер или VPS** — через cron:

```
0 9 * * * cd /path/to/parser-airsoft && .venv/bin/python -m airsoft_news --send-telegram
```
